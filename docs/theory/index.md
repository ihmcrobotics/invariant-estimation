`anchor_release_timing` derives the vertical sink: the contact Jacobian is a
difference operator, so how a liftoff residual splits between base and anchor is
set entirely by the *relative* covariance, and a full stance drives that 500x too
tight. It ends with the property a fix must satisfy, which is stronger than any
sink number.

`contactnet_open_questions` is the handoff for the ContactNet theory work: what is
settled, what is measured, and the six questions that remain. It links back to
`PORT_NOTES.md` for every number rather than restating them.
